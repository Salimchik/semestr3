This repository contains my solutions, notes, exercises, and final project for **CS50's Introduction to Programming with R** by Harvard University.

The course focuses on programming with R, data analysis, data visualization, testing, and packaging.

## Course Overview

CS50R is an introduction to programming using **R**, a language widely used for statistical computing, data analysis, and visualization.

Throughout the course, I will work with:

- Vectors, matrices, arrays, lists, and data frames
- Conditions, loops, and functions
- Data transformation with `tidyverse`
- Data visualization with `ggplot2`
- Testing and debugging R programs
- R packages and reproducible projects
